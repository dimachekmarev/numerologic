# Открыть Numerologic

1. Распакуйте архив целиком.
2. На Mac откройте `start.command`. Если macOS блокирует открытие: правый клик → «Открыть».
3. Браузер откроется автоматически. Первый запуск устанавливает зависимости; нужен интернет и Python 3.10+.

На Windows: `python launch.py`. На Linux: `python3 launch.py`.

В архиве уже собран интерфейс: Node.js не требуется. При запуске из GitHub без готовой сборки launcher соберёт интерфейс; в этом случае нужен Node.js 22+.

Это локальная демонстрационная версия полноценного приложения: дневник, цели, календарь, практикумы, кабинет, отчёты и PDF. Создайте аккаунт с любым своим email; подтверждение почты в демоверсии не требуется. Покупки тестовые, деньги не списываются. Пробуйте клуб и разовые материалы.

AI включается отдельным серверным ключом `AI_API_KEY`; без него интерфейс честно показывает, что помощник ещё не подключён. Восстановление пароля по email требует SMTP. При тесте не забывайте выбранный пароль.

Профиль и записи сохраняются между перезапусками. На Mac данные находятся в `~/Library/Application Support/Numerologic`; на Linux — в `~/.local/share/Numerologic`. Доступные варианты: экспорт своих данных и удаление аккаунта внутри приложения.

Для остановки: Ctrl+C в окне запуска. Для повторного открытия снова запустите `start.command`.

Для постоянного доступа с телефона и других устройств приложение нужно развернуть на вашем сервере с HTTPS. Готовая конфигурация Docker/Caddy включена, инструкция — README.md. GitHub Pages не запускает сервер этого приложения.
