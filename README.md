# Numerologic 3.0

Многостраничное личное пространство: карта чисел, тема дня, дневник, цели, календарь, практикумы, материалы/PDF и обзор недели.

Онлайн: https://numerologic.dimachek777.chatgpt.site — сохранён прежний проект, доступ владельца не менялся. React и облачный Worker/D1 работают на одном домене. Данные аккаунта хранятся на сервере.

## Рабочие сценарии

- Пять шагов мини-разбора → сохранённый профиль → полная карта чисел. 11/22/33 сохраняются; периоды сводятся к 1–9. Расчёт открыт, frontend и Worker используют один модуль.
- Аккаунт с паролем и одноразовым резервным кодом. Восстановление через email + код, смена пароля, выход со старых устройств.
- Дневник: запись за день, черновик в текущей вкладке, редактирование, удаление, поиск по всей истории, страницы по 20 записей.
- Цели: создание, изменение срока/текста, выполнение, удаление и фильтры.
- Календарь по дням недели, переход в дневник за выбранный день.
- Обзор реальных наблюдений за семь календарных дней: настроение, шаги, цели, последовательность записей.
- Первый день каждой практики бесплатен и допускает отметку выполнения.
- Семь дней полного пробного доступа, один раз на зарегистрированный аккаунт. Без карты и списаний. Материалы формируются и сохраняются в кабинете; скачанный или сформированный материал остаётся после пробного периода.
- Карта чисел в PDF бесплатно; полные тематические отчёты и практикумы — в пробном доступе или по праву на материал.
- Экспорт всех личных записей и удаление аккаунта.
- Четыре готовых упражнения бесплатно. Они явно обозначены как библиотечные упражнения, а не ответы AI.

## Внешние подключения

Приём денег отключён отдельно по указанию владельца. `PREVIEW_MODE=false` отключает тестовые покупки в опубликованной версии. Нет имитации выручки или подтверждения платежей со страницы успеха.

AI подключается серверными переменными `AI_API_KEY`, `AI_BASE_URL`, `AI_MODEL`. В текущем окружении ключ не задан. До его подключения интерфейс показывает честный статус и предлагает готовые упражнения. Провайдер получает профиль, семь последних записей и историю только при обращении к AI. Лимит — десять сообщений в день; при ошибке провайдера сообщение не расходует лимит.

Для коммерческих продаж также нужны реквизиты продавца, платёжный провайдер и проверка живой оплаты. Python-адаптеры сохранены в backend/; это альтернативный контур, а не текущий облачный runtime. Его прежняя документация — docs/SELF_HOST_LEGACY.md.

## Локальный запуск того же продукта

Нужен Node.js 22+. На Mac: start.command, Windows: start.cmd, в терминале:

```sh
node hosting/launch.mjs
```

Первый запуск устанавливает зависимости и собирает приложение. База сохраняется в пользовательской папке Numerologic, а не в репозитории. Локально и онлайн базы отдельные. `NUMEROLOGIC_DATA_DIR` задаёт папку данных, `NUMEROLOGIC_PORT` — порт. Данные ограничены локальным пользователем файловыми правами. Старая Python-точка launch.py теперь запускает тот же Worker.

## Разработка и проверки

```sh
npm ci
npm ci --prefix frontend
npm run build
npm run test:hosted
```

Схема D1 — drizzle/. Персональные данные не входят в Git. Ключи находятся только в runtime-переменных. `.openai/hosting.json` сохраняет исходный Sites project_id. Не создавайте новый проект для очередного выпуска.

Проверки и их ограничения: docs/QA_RELEASE_3.md.
