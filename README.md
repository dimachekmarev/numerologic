# NUMEROLOGIC

Коммерческий MVP PWA-сервиса для нумерологических разборов.

## Что это

NUMEROLOGIC — статический веб-продукт без backend:

- лендинг для продажи консультаций;
- бесплатный нумерологический калькулятор;
- расчет числа жизненного пути, предназначения, души, личности и персонального года;
- лид-форма с сохранением заявок в `localStorage`;
- PWA-режим и офлайн-кэш;
- SEO/OG-мета, политика и условия.

## Быстрый запуск

```bash
python3 -m http.server 8080
# открыть http://localhost:8080
```

## Коммерческий сценарий

1. Пользователь получает бесплатный мини-разбор.
2. Видит интерпретацию под свой запрос.
3. Оставляет контакт и заявку.
4. Продавец вручную забирает лид и продает пакет: мини-разбор, глубокий профиль, премиум.

## Что нужно добавить для полноценного SaaS

- Backend/API для заявок.
- Админку лидов.
- Онлайн-оплату.
- Генерацию PDF-отчетов.
- Авторские тексты интерпретаций и промпты для глубоких разборов.
- Аналитику: цели, UTM, конверсия калькулятор → заявка.

## Стек

Vanilla HTML/CSS/JS, PWA service worker. Без сборщика и зависимостей.
