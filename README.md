# NUMEROLOGIC

RU PWA-продукт для продажи подписки на персональные нумерологические прогнозы.

## Позиционирование

NUMEROLOGIC — не просто калькулятор даты рождения. Это подписочный продукт для RU-сегмента: человек получает быстрый бесплатный мини-разбор, видит демо личного кабинета и оставляет заявку на ежемесячный прогноз.

Целевая аудитория первого запуска:

- женщины 25–45;
- эксперты, самозанятые, предприниматели;
- люди в период выбора: работа, отношения, запуск, переезд, личный кризис;
- аудитория Telegram/VK/Дзен, которой нужен мягкий эзотерический продукт без агрессивных обещаний.

## Что есть в продукте

- Продающий лендинг на русском.
- Бесплатный расчет: путь, предназначение, душа, личность, личный месяц.
- Демо личного кабинета подписчика.
- Календарь сильных дат.
- Тарифы подписки: 490 ₽ / 1 490 ₽ / 7 900 ₽ в месяц.
- Лид-форма с локальным сохранением заявок.
- Telegram-handoff для ручной продажи.
- PWA manifest и service worker.
- Политика конфиденциальности, условия, robots, sitemap.

## Быстрый запуск

```bash
python3 -m http.server 8080
# открыть http://localhost:8080
```

## Продажная воронка

1. Трафик из Telegram/VK/Дзен/shorts → лендинг.
2. Бесплатный расчет → эмоциональный крючок.
3. Демо кабинета → понимание регулярной ценности.
4. Заявка → ручная оплата.
5. Доступ в закрытый Telegram-канал подписчиков.
6. Ежемесячный PDF/посты/совместимость/ответы.

## Что подключить следующим этапом

- Домен и публикация: GitHub Pages / Cloudflare Pages.
- Оплата: ЮKassa, CloudPayments, Prodamus или Boosty как быстрый старт.
- Закрытый Telegram-канал для подписчиков.
- Backend/CRM для заявок.
- Генерация PDF-прогнозов.
- Метрика: Яндекс.Метрика, цели, UTM.

## Важное юридическое ограничение

Продукт должен подаваться как инструмент саморефлексии, планирования и развлечения. Нельзя обещать гарантированный доход, лечение, судьбоносные предсказания или замену профессиональных консультаций.
