## Что требует подключений

Реальные платежи Яндекс Пэй/Сплит и ЮKassa, AI-провайдер, SMTP и n8n/CRM проверены на уровне адаптеров с тестовыми ответами. Боевые API-вызовы и списания не выполнялись: ключи и сервер пользователя не предоставлены.

Docker-конфигурация подготовлена, но контейнер не запускался в этой среде: Docker недоступен. Приложение запускалось напрямую как FastAPI + собранный React на одном origin.

## Пределы текущей версии

- Клуб на 30 дней с ручным продлением; автоматических списаний нет.
- Астрология — календарный солнечный знак и темы. Натальная карта и астрономические расчёты не заявлены.
- Самостоятельные практики, не психотерапия и не диагностические тесты.
- В самостоятельной Python-версии SQLite и один worker; онлайн-версия использует облачную D1.
- Старые данные не мигрированы автоматически: новая база без опубликованных персональных данных.
- Страницы продавца нужно дополнить реальными реквизитами до приёма денег.
- Приватная онлайн-версия размещена на Sites с облачным Worker API и D1. GitHub Pages не используется для этой версии.
