# Проверка Numerologic 3.0 — 14 октября 2026

## Подтверждено в текущем выпуске

- Production-сборка React и Cloudflare Worker прошла.
- 24 проверки Worker API на реальном SQLite-адаптере запросов D1 прошли.
- 28 тестов альтернативного Python-backend прошли после исправления мастер-чисел.
- Проверены 11/22/33, реальные даты и PDF с кириллицей.
- Проверены cookie, смена сессии при регистрации, вход/выход, одноразовое восстановление по коду и смена пароля с отзывом других сессий.
- Проверены права владельца дневника, целей, отчётов и PDF; экспорт и удаление данных.
- Проверены 65 записей, четыре страницы, поиск самой старой записи, редактирование по дате и удаление.
- Проверены пробный доступ без оплаты, повторное нажатие, истечение, права на полные практики и идемпотентное формирование материалов.
- Проверены дневник, цели, календарь, семь календарных дней обзора и готовые упражнения.
- AI-адаптер проверен с тестовым HTTP-провайдером: история, десять успешных сообщений в день, кэш вопроса дня, возврат квоты при ошибке. Это не живой вызов провайдера.
- При выключенном приёме денег создание/подтверждение тестовых оплат запрещено.

## Ограничения проверки

Браузерная проверка текущего выпуска не выполнялась: отсутствует control-browser в managed-среде. Сценарий frontend/tests/e2e.mjs обновлён для пробного доступа и 14 маршрутов, но не запускался. Прошлые снимки и browser-отчёты не служат подтверждением текущего выпуска.

AI-провайдер не подключён в production. SMTP, Telegram/CRM и реальные платежи не проверены и не заявляются работающими. Восстановление реализовано резервным кодом без зависимости от SMTP.

Сохраняется прежний приватный доступ владельца. Это не публичный коммерческий запуск. Приём денег по договорённости подключается отдельно.
