# Публикация NUMEROLOGIC в интернет

Код уже готов и запушен в `main`.

## Включить GitHub Pages вручную

1. Открыть репозиторий: https://github.com/dimachekmarev/numerologic
2. Settings → Pages.
3. Source: `Deploy from a branch`.
4. Branch: `main`, folder: `/root`.
5. Save.
6. Через 1–3 минуты сайт будет доступен по адресу:
   https://dimachekmarev.github.io/numerologic/

## Почему не включено автоматически

Текущий GitHub token авторизован для push кода, но не имеет права `pages` для API-включения GitHub Pages (`403 Resource not accessible by personal access token`).

## После публикации

- подключить домен;
- поставить Яндекс.Метрику;
- заменить ручную заявку на оплату ЮKassa/CloudPayments/Prodamus;
- подключить отдельный Telegram-канал Numerologic для операций и подписчиков.
